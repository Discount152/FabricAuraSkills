# Server Requirements

GraniteSkills requires the following server environment to run, as of version `2.3.7`:

* Paper, Purpur, Folia, or Spigot server
  * Note: Spigot is not recommended. Paper is a drop-in replacement.
* Minecraft 1.20 or newer (latest is always recommended)
* Java 21 or newer

You can view the most up-to-date list of supported Minecraft versions on [Modrinth](https://github.com/Discount152/FabricAuraSkills/version/latest?loader=paper).

Additionally, ensure your server and other plugins aren't in the list of [incompatibilities](incompatibilities.md).
